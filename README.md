# The Last Empiricists

An immersive and modern website created for **The Last Empiricists**, a novel project. The website is designed to provide readers with an engaging digital experience while presenting the novel, its themes, and related content through a clean and atmospheric interface.

## ✨ Features

* 📖 Dedicated novel presentation
* 🎨 Immersive and modern UI/UX
* 🌌 Atmospheric visual design
* 📱 Responsive layout for desktop and mobile devices
* ⚡ Smooth interactive elements
* 📄 Integrated novel reading experience
* ⬇️ Novel PDF access
* 🖼️ Dedicated visual presentation for the novel
* 🧭 Intuitive navigation
* 🚀 Fast Vite-powered development and production builds

## 🛠️ Tech Stack

### Frontend

* React 19
* TypeScript
* Vite
* Tailwind CSS

### Utilities

* clsx
* tailwind-merge

## 🚀 Getting Started

### 1. Install dependencies

After opening the project folder in your terminal, run:

```bash
npm install
```

### 2. Start the development server

```bash
npm run dev
```

Vite will provide a local development URL where the website can be viewed.

### 3. Build for production

```bash
npm run build
```

### 4. Preview the production build

```bash
npm run preview
```

## 📖 About the Project

**The Last Empiricists** is a creative web project built around the presentation of a novel.

Rather than treating the website as a simple document or book landing page, the goal was to create an immersive digital environment that complements the identity of the novel.

The interface focuses on visual storytelling, readability, navigation, and creating an engaging experience for visitors.

## 🎯 Project Goals

* Create a distinctive online presence for the novel
* Make the reading experience easily accessible
* Combine storytelling with modern web design
* Build a responsive experience across different screen sizes
* Present the novel in a visually engaging way

## 💡 Design Approach

The website was designed with a strong emphasis on **immersive UI/UX**.

Key design principles include:

* Clear visual hierarchy
* Atmospheric presentation
* Minimal and purposeful layouts
* Smooth interactions
* Responsive design
* Focus on the novel's identity and content
